# Projeto: Interface IA chat - Jarvis de Harry

O projeto é uma inteface inicial de chat com iA semeljante ao chatgpt, Claude, Grock e etc.

## Aspectios visuais
A tela deve ser escura(darK) e o campo de busca no meio da tela.

Dentro da área de campo de busca deve ter:
-Na parte inferior esquerda:
-- Botâo (que ativa/desativa) dizendo "Pensamento profundo"
-- Botão (que ativa/desativa) dizendo "Pesquisa Iteligente"
-Na parate inferiror direita:
--Botão de enviar, arredondado
Acima da área de campo de busca deve ter 3 opções (como tabas) para slecionar:
_Rápido
_Especialista

Acima deles, o nome do projeto Jaarvis de Harry

## Aspectos técnicos

O projeto usa Vite + React + Typescript + Tailwind

O Projeto deve usar componentes na pasta src/components, devidamente organizados e sem repetir componentes desnecessáriamente.
